# 05. 검사

사용자에게 보여 주기 전에 전부 통과해야 한다. 하나라도 실패하면 고친 뒤 처음부터 다시 검사한다.

## 체크리스트

| # | 항목 | 기준 | 방법 |
|---|---|---|---|
| 1 | 멈춘 화면 | **0개** (0.7초 이상 정지 구간) | `ffmpeg -i final.mp4 -vf freezedetect=n=0.003:d=0.7 -map 0:v -f null - 2>&1 \| grep freeze_start` 결과 없음 |
| 2 | 잘린 글자 | **0개** | 장면별 스틸을 눈으로 확인 + 자막 박스 좌표가 안전 영역 안인지 코드로 확인 |
| 3 | 소리 크기 | -14 LUFS ±1, 최대 -1 dBTP 이하 | `ffmpeg -i final.mp4 -af ebur128=peak=true -f null - 2>&1 \| tail -12` |
| 4 | 길이 | 40~60초 | `ffprobe -v error -show_entries format=duration -of csv=p=0 final.mp4` |
| 5 | 규격 | 1080×1920, 30fps | `ffprobe` |
| 6 | 자막 박자 | 단어 시작보다 0~0.15초 앞 | `words.json`과 렌더 props 비교 |
| 7 | 사실 번호 | 대본·화면의 모든 숫자에 `[F#]` 있음, 상태 `확인` 또는 `자사주장` | `script.md` 검사 |
| 8 | 목소리·화면 숫자 일치 | 100% | 대본(읽는 말) ↔ 자막(숫자) 대조 |

## 장면별 스틸

```
for each scene in scenes.json:
  ffmpeg -ss <scene.start + 0.5> -i final.mp4 -frames:v 1 check/scene_<id>.png
```

뽑은 사진을 **한 장씩 직접 열어 본다.** 확인 항목: 글자 잘림, 겹침, 오탈자, 빈 화면, 브랜드 색.

## 보고 형식

```
검사 통과 (8/8)
- 길이 52.3초 · -14.2 LUFS · 최대 -1.4 dBTP · 멈춘 화면 0 · 잘린 글자 0
- 장면 12개 스틸 확인 완료: check/
- 사실 7개 (확인 5 · 자사주장 2)
```
