# 모션편집: 운영 절차

세로 쇼츠 한 편을 만들 때마다 아래 7단계를 순서대로 지킨다. 단계를 건너뛰지 않는다.
세부 규칙은 번호 파일에 있다. 해당 단계에 들어가기 전에 그 파일을 읽는다.

| 단계 | 할 일 | 결과물 | 규칙 파일 |
|---|---|---|---|
| 0 | 자료 찾기 · 사실 확인 | `research.md` (출처 달린 사실 목록) | `00_사실검증.md` |
| 1 | 레퍼런스 뜯어보기 (있을 때) | `reference_breakdown.md` (장면 순서표) | `02_박자.md` |
| 2 | 대본 | `script.md` (10~13줄) | `01_대본.md` |
| 3 | 목소리 → 단어 시각표 | `voice.wav`, `words.json` | `02_박자.md` |
| 4 | 장면표 | `scenes.json` | `02_박자.md`, `03_화면.md` |
| 5 | 화면 (Remotion) | `out/raw.mp4` | `03_화면.md` |
| 6 | 소리 | `out/final.mp4` | `04_소리.md` |
| 7 | 검사 | `check/` 장면별 스틸 + 검사 로그 | `05_검사.md` |

## 불변 원칙

1. **목소리가 먼저, 화면은 나중.** 화면을 목소리 박자에 맞춘다. 반대로 하지 않는다.
2. **틀린 숫자는 영상 전체를 죽인다.** 화면·대본에 나오는 수치는 전부 `research.md`의 출처와 1:1로 묶는다. 출처 없는 숫자는 쓰지 않는다 (`00_사실검증.md`).
3. **검사 통과 전에는 보여 주지 않는다.** 멈춘 화면 0, 잘린 글자 0, 소리 크기 기준 통과, 장면별 스틸 확인이 끝나야 사용자에게 넘긴다.
4. **대본 승인 전에는 목소리를 만들지 않는다.** 대본이 나오면 먼저 보여 주고, 사용자가 좋다고 해야 3단계로 넘어간다. 처음 만드는 주제는 앞 10초만 먼저 만들어 보여 준다.
5. **고친 건 규칙으로 남긴다.** 같은 수정을 두 번 하게 되면 해당 규칙 파일에 한 줄 추가하고, 무엇을 추가했는지 사용자에게 알린다 (`references/기준작.md`, 아래 "폴더 키우기").

## 작업 폴더

영상 한 편마다 `shorts/<YYYYMMDD>_<주제-슬러그>/` 하나를 만든다. 위 표의 결과물은 전부 이 안에 둔다.
Remotion 프로젝트는 `shorts/_studio/` 한 곳에 두고 재사용한다 (최초 1회 설치는 `references/도구설치.md`).

## 말로 고치기

사용자가 "N초쯤 ~해 줘"라고 하면:
1. `words.json`에서 N초 전후 문장을 찾아 해당 장면 id를 특정한다.
2. 그 장면만 수정한다. 숫자·단어를 바꾸는 요청이면 **대본 → 목소리 → 시각표 → 화면** 순서로 둘 다 바꾼다 (목소리와 화면 숫자가 어긋나면 안 됨).
3. 수정 구간만 다시 렌더하고, 7단계 검사를 전체에 다시 돌린 뒤 보여 준다.

자주 나오는 요청 → 처리:

| 요청 | 처리 |
|---|---|
| "자막이 말보다 늦어요" | `words.json` 재생성 후 자막 선행 오프셋을 2~3프레임 더 당긴다 |
| "N초쯤 심심해요" | 그 문장의 핵심 단어마다 그림·숫자·카드 등장 이벤트를 추가 |
| "숫자를 X로" | `research.md` 출처 확인 → 대본·목소리·화면 동시 수정 |

## 폴더 키우기

- 작업이 끝날 때 "오늘 고친 것 중 다음 영상에도 해당되는 것"을 골라 규칙 파일에 한 줄씩 추가하고, 추가한 줄을 사용자에게 보여 준다.
- 사용자가 "이 영상을 기준작으로"라고 하면 `references/기준작.md`에 경로·길이·장면 수·잘 된 점을 적는다. 다음 영상은 기준작 수준(장면 밀도, 자막 박자)에 맞춘다.

## 회사 소재

화우나노텍 주제는 `references/화우_소재.md`의 주제 은행과 사실표를 먼저 본다. 사실표에 "확인 필요" 표시가 있는 수치는 사용자 확인 전까지 화면에 쓰지 않는다.
