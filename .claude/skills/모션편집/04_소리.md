# 04. 소리

## 순서

1. 목소리 먼저 (`voice.wav`) → 화면은 목소리에 맞춘다.
2. 화면 렌더 후 소리를 섞는다.
3. 완성본만 살짝 빠르게.

## 규칙

| 항목 | 값 | ffmpeg |
|---|---|---|
| 완성본 속도 | 목소리 1.08~1.12배, 음높이 유지 | `atempo=1.1` (음높이 유지됨) |
| 배경 음악 | 목소리보다 18~22dB 낮게, **원래 속도**, 끝 2초 서서히 줄임 | `volume=-20dB`, `afade=t=out:st=<끝-2>:d=2` |
| 효과음 | **장면 바뀔 때만**, 한 편에 열 개 안팎. 단어마다 반짝 소리 금지 | `adelay`로 장면 시작 시각에 배치 |
| 전체 크기 | 통합 라우드니스 **-14 LUFS**, 순간 최대 -1 dBTP | `loudnorm=I=-14:TP=-1:LRA=11` |

- -14 LUFS(소리 크기 단위)는 유튜브·인스타그램 업계 통용 기준치다. 플랫폼이 공식 고정값으로 공개한 수치는 아니다.
- 속도를 올리면 `words.json` 시각을 같은 배율로 나눠 화면을 렌더한다. 화면을 나중에 빠르게 돌리지 않는다 (모션 프레임이 뭉개진다).

## 배경 음악 출처

- 저작권이 확인된 음원만 쓴다: 유튜브 오디오 보관함, 직접 구매한 라이선스, 자체 제작.
- 사용한 음원 이름과 라이선스를 작업 폴더 `credits.md`에 적는다.

## AI 목소리

- 일레븐랩스 등 AI 목소리는 해당 서비스 요금이 따로 든다. 상업 이용이 허용되는 요금제인지 확인한다.
- 실존 인물 목소리 복제는 본인 동의가 있을 때만 쓴다.
