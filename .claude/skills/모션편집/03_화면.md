# 03. 화면 (Remotion)

## 캔버스

- 1080×1920, 30fps, H.264, yuv420p.
- **안전 영역(실무 기준치, 플랫폼 공식 수치 아님):** 위 220px, 아래 420px, 오른쪽 140px에는 핵심 글자를 두지 않는다. 플랫폼 UI(버튼·설명란)에 가려진다.

## 첫 2~7초

- **판 하나 덩그러니 금지.** 화면 전체에 흐르는 배경(격자·물결·기포 입자)을 깔고 그 위에 카드·글씨를 겹친다.
- 화우나노텍 기본 배경: 짙은 남색 위로 올라가는 미세 기포 입자 + 느린 격자 흐름.

## 단어마다 변화

- 핵심 단어가 나오는 프레임에 그림·숫자·카드가 들어온다.
- 등장 모션: `spring` 스케일 0.85→1.0 + 회전 ±2° 흔들림, 길이 8~12프레임.
- 숫자는 0에서 목표값까지 카운트업(올라가는 숫자)으로 보여 주고, 단위는 숫자보다 작게.
- 카드·그림은 **멈춘 사진보다 움직이는 실제 영상 조각**을 쓴다. 자사 현장 영상이 있으면 그걸 1순위로 쓴다.
- 이벤트가 1.5초 넘게 없으면 배경이라도 움직이게 한다. **멈춘 화면은 없게.**

## 자막

- 위치: **위쪽에 크게.** 기준선 y≈300~560 (안전 영역 안).
- 글꼴: Pretendard ExtraBold (SIL 오픈 폰트 라이선스, 상업 이용 가능), 64~76px, 줄당 최대 12자.
- 색: **지난 단어 회색(#9AA0A6), 지금 단어 흰색 굵게(#FFFFFF).** 문장마다 반투명 선택 상자 하나.
- 자막 텍스트는 `words.json`의 단어 단위로 띄운다 (`02_박자.md`의 선행 오프셋 적용).
- 화면 자막 숫자는 아라비아 숫자 + 단위 (예: 10억 개/mL).

## 진행자 (넣는 경우만)

1줄 전체 화면 → 2줄부터 아래 작은 원형 창 → 마지막 줄 다시 전체 화면.

## 렌더

```
cd shorts/_studio
npx remotion render src/index.ts Short ../<작업폴더>/out/raw.mp4 --props=../<작업폴더>/props.json
```

`props.json`에는 `words.json`, `scenes.json`, 에셋 경로를 담는다. 컴포지션 코드는 영상마다 새로 짜지 않고 props만 바꾼다.

## 썸네일 (덤)

- 2종 만들어 사용자에게 고르게 한다. 1080×1920 PNG (`npx remotion still`).
- 큰 숫자 1개 + 제목 2줄(위 흰색, 아래 금색 크게) + 작은 알약 모양 라벨 1개.
- 비결·도구 이름은 썸네일에 쓰지 않는다 (영상에서 공개).
