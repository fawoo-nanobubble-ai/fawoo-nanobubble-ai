# 02. 박자 (레퍼런스 · 단어 시각표 · 장면표)

## A. 레퍼런스 뜯어보기

잘 된 쇼츠를 참고할 때는 말과 화면이 바뀌는 순간을 장면 순서표로 먼저 적는다. 저장: `reference_breakdown.md`.

1. 영상 파일이나 주소를 받는다. 주소만 있고 받을 수 없으면 사용자에게 파일을 달라고 한다.
2. 대사 받아쓰기: `whisper` 단어 시각표로 그대로 받아 적는다.
3. 장면 전환 시각: `ffmpeg -i ref.mp4 -vf "select='gt(scene,0.3)',showinfo" -f null - 2>&1 | grep pts_time`
4. 표로 정리:

```
| 시각 | 그 순간 단어 | 화면에 들어온 것 | 움직임 | 자막 위치·모양 |
```

5. 마지막에 **훅(첫 2~7초) 구조, 문장 순서, 끝맺음**과 "내 영상에 쓸 공식 3개"를 적는다.

## B. 단어 시각표

1. 목소리를 **먼저** 만든다 (`voice.wav`). 녹음 파일 또는 AI 목소리.
2. 받아쓰기로 단어마다 시작·끝 시각을 뽑는다 → `words.json`

```json
[{"w":"여러분","s":0.00,"e":0.42,"line":1}, ...]
```

3. 받아쓰기 결과를 `script.md`와 대조해 틀린 단어를 대본 글자로 바로잡는다 (시각은 유지).
4. **자막 선행 오프셋:** 자막은 단어 시작보다 **3프레임(0.1초)** 앞당겨 띄운다. 사람 눈에는 이게 "딱 맞게" 보인다.
5. 속도를 올리는 경우(`04_소리.md`), 시각표도 같은 배율로 나눈다. 렌더는 **최종 속도 기준 시각**으로 한다.

## C. 장면표

- **문장 1줄 = 장면 1개.** 장면은 그 문장의 **첫 단어 시작 시각**에서 바뀐다.
- 장면 안에서 **핵심 단어**(숫자·고유명사·동사 1~3개)마다 등장 이벤트를 단다.
- 저장: `scenes.json`

```json
[{
  "id": 1, "line": 1, "start": 0.00, "end": 2.10,
  "bg": "flow-grid",
  "events": [
    {"at": 0.35, "word": "소름", "type": "card-pop", "asset": "assets/bubble_macro.mp4"}
  ]
}]
```

- 이벤트 사이 간격이 **1.5초를 넘으면** 그 사이에 움직임을 하나 더 넣는다 (멈춘 화면 방지).
