# 도구 설치 (최초 1회)

## 필요한 것

| 도구 | 용도 | 확인 명령 |
|---|---|---|
| Node.js 18+ | Remotion 실행 | `node -v` |
| Remotion | 코드로 움직이는 화면 만들기 | `npx remotion --version` |
| ffmpeg | 영상·소리 붙이기·자르기·검사 | `ffmpeg -version` |
| Whisper | 목소리 받아쓰기 + 단어 시각표 | `whisper --help` |

## 설치 순서

1. `shorts/_studio/`에 Remotion 빈 프로젝트를 만든다: `npx create-video@latest` → blank 템플릿.
2. 컴포지션 `Short`: width 1080, height 1920, fps 30, 길이는 props에서 계산.
3. ffmpeg: macOS `brew install ffmpeg`, Windows `winget install Gyan.FFmpeg`, Linux `apt install ffmpeg`.
4. Whisper: `pip install openai-whisper` → 사용 `whisper voice.wav --language ko --word_timestamps True --output_format json`.
   느리면 whisper.cpp 또는 faster-whisper로 바꾼다.
5. 확인: 3초짜리 시험 영상(흐르는 배경 + 글자 하나)을 렌더해서 재생한다.

설치 중 승인 창이 나오면 무엇을 하는 명령인지 사용자에게 설명한 뒤 진행한다.
