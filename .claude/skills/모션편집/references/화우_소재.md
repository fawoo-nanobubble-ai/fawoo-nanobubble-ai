## 화면 소재 우선순위

1. 자사 현장·실험 영상 (발생기 작동, 수조, 현장 배관)
2. 측정 장비 화면 (입도 분석기 그래프 등), 실제 데이터일 때만
3. 직접 만든 모션 그래픽 (기포 입자, 분자 모식도)
4. 저작권 확인된 스톡 영상
