# 00. 자료 찾기 · 사실 검증

원본 가이드에는 없는 단계다. 기술 기업 홍보 영상은 숫자 하나가 틀리면 신뢰가 무너지기 때문에 맨 앞에 둔다.

## research.md 형식

```
| # | 사실 (한 문장) | 수치 | 출처 (URL·문서명·쪽) | 확인일 | 상태 |
|---|---|---|---|---|---|
| F1 | 나노버블은 지름 1μm 미만 기포 | <1 μm | ISO 20480-1:2017 | 2026-10-29 | 확인 |
| F2 | 자사 기포 밀도 | 1.0×10⁹ 개/mL | 회사 README (자사 주장) | 2026-10-29 | 자사주장 |
```

- 상태는 `확인` / `자사주장` / `확인 필요` 셋 중 하나.
- 대본의 숫자 옆에 `[F1]`처럼 사실 번호를 단다. 렌더 전 `script.md`에서 번호 없는 숫자를 찾으면 멈춘다.

## 규칙

1. **출처 없는 숫자 금지.** 모르면 "확인 필요"로 두고 사용자에게 묻는다. 추정치를 사실처럼 쓰지 않는다.
2. **자사 주장은 자사 주장으로 말한다.** 시험성적서·특허·논문으로 뒷받침되기 전까지는 "화우나노텍 측정 기준"처럼 주체를 밝힌다.
3. **최상급 표현 금지.** "세계 최초", "최고", "유일", "100%"는 객관적 근거(공인 시험, 공식 순위)가 `research.md`에 있을 때만 쓴다. 근거 없는 최상급 표현은 표시·광고의 공정화에 관한 법률(표시광고법)상 부당 광고 소지가 있다.
4. **효능 표현 주의.**
   - 농업: "수확량 N% 증가"는 시험 조건(작물·기간·대조군)을 화면 하단에 작게 함께 쓴다.
   - 수질·환경: "완전 제거", "무해" 같은 단정 대신 측정값과 기준을 쓴다.
   - 사람 건강 효능(피부·질병 등)은 다루지 않는다.
5. **경쟁사 비교**는 이름을 쓰지 않거나, 같은 조건의 공개 데이터가 있을 때만 쓴다.
6. **확인일**을 남긴다. 정책·시장 수치는 6개월이 지나면 다시 확인한다.
