# 화우 모션 덱 (PPT Motion Kit 워크플로)

출처: @jay.ai.gtm 「PPT 모션 키트로 디자인 시스템 만들고 발표 덱까지 클로드로 끝내기」(2026.10) 가이드의 절차를 화우나노텍 기준으로 고정한 것. 키트 파일(config.js, effects-a/b.js 등) 자체는 이 스킬에 포함하지 않는다(원작자 허가 없는 재배포 금지).

## 0. 전제

| 환경 | 렌더링 방식 |
|---|---|
| Claude 데스크톱/웹 + 디자인 시스템 등록됨 | `PPT Motion Kit Design System`(https://claude.ai/artifact/Qyn4Y2sBsdfZBkVL7DL2Qr) 체크 후 덱 생성 → Export |
| 디자인 시스템 미등록 / Claude Code | `anthropic-skills:pptx`로 .pptx 생성, 모션이 필요한 장은 단일 HTML(Chrome 재생)로 별도 생성 |

디자인 시스템이 체크돼 있는지 먼저 확인한다. 안 돼 있으면 사용자에게 한 줄로 알리고 위 대체 경로로 진행한다.

## 2. 절차 (순서 건너뛰기 금지)

1. **자료 수집**: 리포트, 엑셀, 수치 목록을 받는다. 숫자의 출처·기준연도를 표로 정리하고, 같은 항목에 숫자가 2개 이상이면 임의 선택하지 말고 불일치를 사용자에게 알린다.
2. **md 초안**: 장별로 `제목(결론 한 문장) / 핵심 숫자 / 근거 / 출처`만 담은 md를 만든다. 제목은 주제가 아니라 결론으로 쓴다("시장 현황" ✕ → "NCC 폐수 중화 시장, 2030년 2.1배" ○).
3. **시각화 제안**: 아래 프롬프트를 그대로 실행해 장별 시각화 후보를 표로 낸다.
   > 내용과 숫자를 매칭해서 시각화 요소를 제안해줘. 디자인 시스템에 없어도 내용을 잘 표현할 수 있는 시각화 방법이라면 같이 제안해줘.
   출력 표 열: `장 | 핵심 메시지 | 데이터 | 추천 차트(1번표 번호) | 대안 | 텍스트만으로 충분한가`
4. **사람 검토(멈춤)**: 제안표를 보여주고 사용자 확정을 받는다. 확정 전에는 덱을 만들지 않는다.
5. **제작**: 확정된 md + 시각화표로 덱 생성. 장마다 Speaker notes(발표 메모)를 3줄 이내로 붙인다.
6. **검수**: 아래 3번 규칙 위반, 숫자 원본 대조, 글자 넘침을 확인한 뒤 납품한다.
7. **내보내기 안내**: 아래 4번.

## 3. 화우 고정 규칙

- 색: 키트 기본값 그대로. 강조 `a #416180`, 보조 `b #94BCE3`, 배경 `bg #F2F2F3`, 어두운 배경(11·12번) `dark #1D2D3D`. 상태색(빨강·초록) 쓰지 않음. 강조 항목은 한 장에 1~2개.
- 글꼴 숫자: Barlow Condensed.
- 글꼴: Pretendard. 발표 PC에 없으면 키트 `fonts/` 폴더 글꼴 설치 안내.
- 개조식, 명사형 종결. em dash(`—`) 금지, '축' 단어 금지.
- 전문용어·약어는 처음 나올 때 괄호로 풀이. 예: CCU(Carbon Capture & Utilization, 탄소 포집·활용).
- 대외용 덱에 원가 구성·내부 협의 금액 금지. 결과 금액만.
- 한 장에 메시지 1개, 숫자는 단위·기준연도·출처 필수.
- 파일명 `YYMMDD_덱이름`.

## 4. 내보내기

| 용도 | 형식 | 이유 |
|---|---|---|
| 현장 발표 | HTML(.zip) → Chrome 전체화면 | 모션이 가장 덜 깨짐 |
| 팀·고객 공유 | PDF | 레이아웃 고정 |
| 수정 필요 | PowerPoint(.pptx) / Google Slides | 편집 가능, 모션 일부 손실 |
| SNS·홍보 | Video(MP4) | 차트 모션 영상화 |
