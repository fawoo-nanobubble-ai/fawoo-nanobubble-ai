# 프롬프트 2 — 툴박스: 다시 쓸 파일 저장

## 언제 쓰나
- 1단계 직후 job을 실제로 한 번 돌렸고, 다시 쓸 템플릿·스크립트·메일·체크리스트가 방금 나왔을 때
- 쓰지 않는다: 일회성 결과물, 비밀번호·API 키·타인 개인정보가 든 것, 내가 승인 안 한 초안

## 프롬프트 (그대로 붙여넣고 [대괄호]만 바꾼다)

```
방금 만든 [스크립트 / 템플릿 / 메일 / 체크리스트]를 봐.

다시 쓸 거면 아래를 전부 해:
1. .claude/skills/[job-name]/files/ 에 설명적인 이름으로 저장해. 예: numbers-pull.py, update-template.md. 이름에 날짜·버전 번호 넣지 마.
2. 내 구체 값은 [대괄호 자리표시]로 바꾸고, 아래에 채운 예시 하나를 남겨.
3. SKILL.md에서 이 파일이 필요한 단계가 파일명을 가리키게 하고, 언제 쓰고 언제 쓰지 않는지 적어.
4. .claude/skills/[job-name]/files/INDEX.md 에 한 줄 추가: 파일명 | 용도 | 오늘 날짜.

일회성 결과물, 비밀번호·API 키·개인정보가 든 것, 내가 승인 안 한 초안은 저장하지 마.

그다음 job 전체를 처음부터 다시 돌리고, 저장된 파일 중 뭘 썼고 뭘 처음부터 다시 만들었는지 알려줘. 다시 만든 것 중 다음에 저장할 후보도 말해줘.
```

## 채운 예시 (참고용)

```
방금 만든 quote-template.md 를 봐.

다시 쓸 거면 아래를 전부 해:
1. .claude/skills/ccu-concrete-quote-draft/files/ 에 설명적인 이름으로 저장해. ...(이하 위와 동일)
```
