# 정책 보고서 공식 출처 목록

근거를 찾을 때 이 목록부터 확인한다. 여기에 없는 출처를 쓸 때도 발행 기관이 분명한 1차 자료를 우선한다.

## 인용 표기 형식

- 법령: `「법령명」 제○조제○항 (법률 제○○○○○호, 시행 YYYY.MM.DD)`
- 통계: `작성기관, 「통계명」, 기준연도, 단위 (검색일 YYYY.MM.DD)`
- 보고서: `발행기관 (발행연도), 「보고서명」, 쪽`
- 웹 자료: `기관명, 「제목」, URL (검색일 YYYY.MM.DD)`

## 주의

- 부처 명칭과 소관은 정부조직 개편으로 바뀔 수 있다. 부처명은 문서 작성 시점의 정부조직법 기준으로 국가법령정보센터에서 확인한다.
- 법령은 개정이 잦다. 인용 직전에 현행 시행일을 다시 확인한다.
