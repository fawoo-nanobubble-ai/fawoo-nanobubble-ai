# 에이전트 데스크톱 설치·사용 가이드

> 한 줄 결론: **스킬은 레포에 넣어 뒀고, 실제로 엑셀·파워포인트를 움직이려면 내 PC에 본체(CLI) 한 줄 설치 + 권한 켜기만 하면 된다.**

출처: 후킹랩 오로드맵 「에이전트 데스크톱으로 클로드 코드 여러 개에게 컴퓨터 일을 나눠 맡기는 5단계」(2026-11-10)
원본 도구: [vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop) · Apache-2.0 · npm `agent-desktop` 1.2.0

---

## 1. 이게 뭔가

| 항목 | 내용 |
|---|---|
| 정체 | 클로드 코드가 내 PC의 **프로그램 창(엑셀, PPT, 메일, 사내 앱)** 을 읽고 누르게 해 주는 CLI(명령줄 프로그램) |
| 원리 | OS의 접근성 트리(Accessibility Tree, 화면의 단추·칸 목록을 OS가 정리해 둔 구조)를 읽어 번호(ref)로 클릭·입력 |
| AI 내장? | 없음. 판단은 클로드 코드가 하고, 이 도구는 손 역할만 |
| 지원 OS | macOS 13+, Windows 10 1809+, Ubuntu 24.04+ |
| 기본 모드 | headless(백그라운드). 내 마우스·키보드를 안 뺏음 |

### 구성 2개

| 구성 | 역할 | 상태 |
|---|---|---|
| ① 스킬 (사용 설명서) | 클로드 코드가 사용법을 미리 읽어 두는 파일 | ✅ 이 레포 `.claude/skills/agent-desktop/` 에 설치 완료 |
| ② 본체 CLI | 실제로 창을 조작하는 프로그램 | ⬜ **내 PC에 직접 설치해야 함** (아래 2장) |

> 클라우드 세션(claude.ai/code)은 화면이 없는 리눅스 서버라 내 PC 창을 만질 수 없다. 설치 검증은 끝났지만(`agent-desktop 1.2.0` 정상 실행), **실사용은 내 PC의 클로드 코드에서** 한다.

## 2. 내 PC에 설치 (5분)

### 준비물
- 클로드 코드 (터미널 또는 VS Code)
- Node.js 18 이상 (`node -v` 로 확인, 없으면 https://nodejs.org LTS 설치)

### 방법 A — 클로드 코드에 통째로 맡기기 (권장)

내 PC의 클로드 코드 입력 칸에 그대로 붙여 넣기:

```
네가 이 컴퓨터의 앱 창을 다룰 수 있도록 에이전트 데스크톱을 갖추고, 끝나면 아래 표로 보여 줘라.
표: 항목 · 상태 · 내가 할 일 (본체, 스킬, 손쉬운 사용)
본체: npm install -g agent-desktop
스킬: npx skills add https://github.com/vercel-labs/agent-desktop --skill agent-desktop -g
- 위 두 명령 말고, 공식 저장소 https://github.com/vercel-labs/agent-desktop 와 npm 밖에서 받은 것은 쓰지 마라.
- 깔고 나면 agent-desktop status 로 권한을 읽고, 맥에서 손쉬운 사용이 꺼져 있으면 agent-desktop permissions --guide 로 설정 창을 띄워라.
- 내가 켰다고 하면 agent-desktop permissions 로 다시 읽어 표를 고쳐라.
```

`-g` = 전역 설치. 어느 폴더에서 클로드 코드를 열어도 스킬이 잡힌다.

### 방법 B — 직접 명령 입력

```bash
npm install -g agent-desktop
npx skills add https://github.com/vercel-labs/agent-desktop --skill agent-desktop -g
agent-desktop status
```

이 레포를 PC에 클론해서 그 폴더에서 클로드 코드를 열면 스킬은 이미 들어 있으니 **본체만** 깔면 된다.

### 권한

| OS | 할 일 |
|---|---|
| Mac | 시스템 설정 → 개인정보 보호 및 보안 → **손쉬운 사용** → 클로드 코드를 띄운 앱(터미널 / VS Code)을 켬. 둘 다 쓰면 둘 다 켜야 함 |
| Windows | 별도 권한 창 없음. 관리자 권한으로 띄운 프로그램을 조작하려면 터미널도 관리자 권한으로 실행 |

### 설치 확인

`agent-desktop status` 결과에서 `"accessibility":{"state":"granted"}` 가 나오면 끝.

## 3. 바로 써 볼 프롬프트 (화우나노텍 버전)

`[ ]` 안만 바꿔서 클로드 코드에 붙여 넣는다.

### ① 시험 성적서 숫자 → 엑셀 표 + 회의 장표 3장

```
[보고서 파일: 예) ./자료/나노버블_밀도측정_성적서.pdf]
[회의 주제: 예) NCC 강알칼리 폐수 중화 파일럿 결과 보고]
에이전트 데스크톱으로 엑셀을 열어 [보고서 파일]의 핵심 숫자(기포 밀도, 평균 크기, pH 변화, 처리 시간)를 새 표에 넣고, 그 표로 파워포인트 회의 자료를 만들어라.
- 숫자마다 보고서 몇 쪽에서 왔는지 바로 옆 칸에 적어라.
- 장표는 표지, 숫자 요약, 결론 세 장으로 짜라.
- 칸을 채울 때마다 그 칸을 다시 읽어 보고서 값과 같은지 견줘라.
- 두 파일은 [보고서 파일]과 같은 폴더에 두고, 저장한 파일 이름을 알려 줘라.
```

쪽 번호를 붙이게 하는 이유: 옮겨 적다 틀린 숫자가 고객 제안서까지 넘어가는 사고 차단.

### ② 내 화면 안 건드리는 규칙 (한 번만)

```
앞으로 에이전트 데스크톱을 쓸 때마다 아래 네 가지를 지켜라.
- ref 로 하는 동작은 기본 설정(headless) 그대로 돌려라.
- --headed 가 있어야 되는 동작이 나오면 실행하기 전에 무엇을 왜 하는지 묻고, 내가 된다고 할 때만 붙여라.
- 윈도우에서 최소화된 창은 focus-window 대신 restore 로 되살려 다뤄라.
- 비밀번호 같은 글은 명령 줄에 적지 말고 --stdin 으로 넘겨라.
- 이 네 가지는 이 프로젝트 CLAUDE.md 맨 아래에 그대로 옮겨 적어라.
```

### ③ 일 세 개 동시에 (이름표 커서)

```
[일 1: 예) 엑셀로 지난달 지역별 나노버블 장비 문의 건수 정리]
[일 2: 예) 메일 앱에 CCU 콘크리트 파트너사 미팅 요청 초안 쓰기]
[일 3: 예) 사내 견적 앱 입력 화면 눌러 보기]
agent-desktop session start --cursor --multi-agent 로 세션을 열고, 하위 에이전트 셋에게 위 일을 하나씩 나눠 맡겨라.
- 에이전트마다 다른 --agent-id 를 주고, 커서 이름표(--label)에는 맡은 일을 두세 낱말로 달아라.
- 셋 다 같은 세션을 쓰되, 누를 단추는 저마다 새로 읽은 목록에서만 골라라.
- 메일은 초안으로 저장만 하고 보내기 단추는 누르지 마라.
- 다 끝나면 agent-desktop session end 로 세션을 닫고, 표: 에이전트 · 맡은 일 · 나온 결과
```

## 4. 리스크 체크

| 리스크 | 대응 |
|---|---|
| 화면의 기밀·개인정보가 스냅샷/클립보드에 그대로 담김 | 작업 전 기밀 창 닫기. `--screenshots` 옵션은 꼭 필요할 때만 |
| 메일·결재 오발송 | 프롬프트에 "보내기/승인 단추는 누르지 마라" 명시 |
| 같은 동작 두 번 실행 (중복 클릭·중복 입력) | 스킬이 `disposition.retry: safe` 일 때만 재시도하도록 이미 규정 |
| 서명 없는 실행 파일이라 Windows SmartScreen·백신 경고 | 받은 곳이 npm 또는 공식 GitHub인지 확인 후 허용 |

## 5. 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| Mac에서 권한 켰는데 `denied` | 클로드 코드를 띄운 **그 앱**(VS Code 등)에도 따로 켜기 |
| Windows에서 글자 입력 거절 | `type` 대신 `set-value` 로 다시 하라고 지시 |
| 창이 여러 개라 대상 불명 | 오류에 나온 창 번호를 `--window-id` 로 넘기게 지시 |
| PowerShell에서 단추 번호 사라짐 | ref를 작은따옴표로 감싸기: `'@s8f3k2p9:e1'` |
| 슬랙 같은 웹 기반 앱이 느림 | 공식 권장: 그 부분은 `agent-browser` 로 |
| 클로드 코드 말고 다른 AI에서 쓰고 싶음 | `agent-desktop mcp` 로 MCP(외부 도구 연결 규격) 서버로 띄우기 |
