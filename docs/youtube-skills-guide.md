# 유튜브 스킬 11개 — 설치 상태와 사용법

> 출처: [Jakeschincariol/youtube-agent-skill](https://github.com/Jakeschincariol/youtube-agent-skill) @ `a2feb21` (MIT 라이선스(자유 사용·수정·배포 허용))
> 소개 글: 디립다 연구소 「클로드 안에 유튜브 담당 직원 두는 법」(2026-11-11)

## 한 줄 요약

주제 하나를 주면 훅 5개 → 점수 → 대본 → 제목·썸네일 → 설명·챕터 → 쇼츠 구간까지 뽑아 준다.
**업로드는 사람이 한다.** 스킬은 글만 쓰고, 모든 결과는 「이대로 갈까요, 고칠까요?」로 끝난다.
API 키(외부 서비스 접속용 인증키)·가입·계정 연결 필요 없음.

## 1. 설치 위치

| 위치 | 용도 | 유지 여부 |
|---|---|---|
| `.claude/skills/yt-*` (이 레포) | 정본. 이 레포를 여는 모든 세션에서 자동 인식 | git에 저장되어 계속 유지 |
| `~/.claude/skills/yt-*` | 지금 세션 전역 사용 | 클라우드 세션은 종료 시 사라짐 |
| `.claude/youtube/voice.md` | 말투 파일 정본 (현재 빈 템플릿) | git에 저장 |

**내 PC(Mac) Claude 앱에서 이 레포 밖에서도 쓰려면** 터미널에서 한 번:

```bash
git clone https://github.com/Jakeschincariol/youtube-agent-skill.git
cp -r youtube-agent-skill/skills/yt-* ~/.claude/skills/
mkdir -p ~/.claude/youtube && cp youtube-agent-skill/templates/voice.md ~/.claude/youtube/
```

(이 레포 안의 `.claude/skills/yt-edit`, `yt-chapters`는 한국어 패치 버전이라 원본보다 낫다. 이 두 폴더는 레포 것을 복사할 것.)

## 2. 스킬 11개 지도

```
 [기획]          [제작]             [포장]              [게시 후]
 /yt-viral  →  /yt-script   →   /yt-package   →   /yt-retention
 /yt-plan       /yt-edit          /yt-seo             /yt-comment
                /yt-shorts        /yt-chapters        /yt-audit
```

| 명령 | 하는 일 | 넣을 것 | 파이썬 도구 |
|---|---|---|---|
| `/yt-script` | 훅 21개 공식으로 5개 생성·채점 → 촬영용 대본(화면 지시 포함) | 주제 1줄 | `hookscore.py` |
| `/yt-package` | 제목+썸네일 문구를 한 쌍으로 작성, 잘림·중복·애매함 검사 | 주제 또는 대본 요약 | `title.py` |
| `/yt-viral` | 내 분야 영상을 **채널 평소 조회수(중앙값) 대비 배수**로 순위 | 분야, 경쟁 채널 목록 | `swipe.py` |
| `/yt-plan` | 실제 가용 시간 기준 주간 계획(메인 1·가벼운 1·쇼츠 3) | 주당 가용 시간, 반쯤 만든 것 | — |
| `/yt-edit` | 자막 파일로 편집 목록: 빈 구간·군말·다시 찍은 곳 + 타임코드 | `.srt`/`.vtt`/Whisper JSON | `deadair.py` |
| `/yt-shorts` | 긴 영상 안의 쇼츠 구간 20~55초 + 새 첫 문장 | 자막 파일 | — |
| `/yt-seo` | 설명란 첫 2줄, 태그(15개 이하), 이겨야 할 검색어 3개 | 영상 요약 | — |
| `/yt-chapters` | 챕터 생성 + 유튜브 규칙 검사(00:00 시작, 3개 이상, 각 10초 이상) | 자막 파일 | `chapters.py` |
| `/yt-retention` | 시청 지속 CSV(유튜브 스튜디오 내보내기)로 이탈 지점과 그때 한 말 | CSV + 자막 | `retention.py` |
| `/yt-comment` | 댓글을 질문·정정·칭찬·악플로 분류, 30단어 이내 답글, 고정 댓글 추천 | 댓글 붙여넣기 | — |
| `/yt-audit` | 채널 전체 진단 → 고칠 것 **딱 1개** | 최근 제목 10개, 썸네일, 첫 15초 | 위 도구 재사용 |

## 3. 먼저 할 일: 말투 파일(voice.md) 채우기

모든 스킬이 `voice.md`를 읽는다. 비어 있으면 결과가 남의 말투로 나온다.

```
내 유튜브 영상 3개 대본이야.
이걸로 .claude/youtube/voice.md 를 채워줘.
[대본 ①] ...
[대본 ②] ...
[대본 ③] ...
```

대본이 아직 없으면 사내 발표 녹취, 고객 미팅에서 설명한 녹취도 된다. "내가 말하는 방식" 그대로가 핵심.

## 4. 화우나노텍용 바로 쓰는 프롬프트

| 목적 | 프롬프트 |
|---|---|
| 대본 | `/yt-script NCC 강알칼리 폐수(pH 13 이상)를 황산 대신 CO₂ 나노버블로 중화하는 원리` |
| 제목·썸네일 | `/yt-package 위 대본. 타깃은 석유화학 공장 환경팀장` |
| 경쟁 분석 | `/yt-viral 산업 폐수처리·탄소포집(CCU). 1위부터 제목·후킹·구성 패턴을 뜯어서 내 다음 영상에 맞게 다시 짜줘` |
| 쇼츠 | `/yt-shorts` + 긴 영상 자막 파일 첨부 |
| 검색 노출 | `/yt-seo CO2 나노버블 콘크리트 양생. 이 영상이 이겨야 할 검색어를 한국어·영어 각 3개` |
| 주간 계획 | `/yt-plan 주 4시간. 반쯤 만든 것: 현장 설치 영상 원본` |

> 대본 속 수치(중화 비용, CO₂ 고정량 등)는 스킬이 지어내지 않고 물어본다. 사내 실측 자료를 준비해 둘 것.

## 5. 한국어 사용 시 한계 (테스트로 확인)

| 도구 | 한국어 상태 | 대응 |
|---|---|---|
| `deadair.py` (편집) | **패치 완료.** 원본은 한글을 지워 군말 "음"·재촬영 반복을 못 잡음 | 레포 버전 사용 |
| `chapters.py` (챕터) | **패치 완료.** 원본은 한국어 제목이 전부 "Section"으로 나옴. 실행할 때마다 제목이 바뀌는 원본 버그도 수정 | 레포 버전 사용 |
| `hookscore.py` (훅 점수) | **영어 전용.** 영어 단어 목록(you, lose, why…)으로 채점. 한국어 훅은 숫자만 반영되고 공식 분류는 "Unclassified" | 영어로 옮긴 문장으로 채점, 점수는 참고용 |
| `title.py` (제목) | 글자 수·숫자 포함 검사는 작동 | 유튜브 제목 잘림은 픽셀 폭 기준. 한글은 영문보다 폭이 넓어 60자 기준이 한국어에는 너그러움 → 모바일 미리보기로 최종 확인 |
| `swipe.py` (바이럴 배수) | 배수 계산 정상. 제목 공식 분류는 영어만 | 배수만 신뢰 |
| `retention.py` (이탈) | 정상 (자막 한국어 그대로 출력) | — |

원저자 고지 그대로: 훅 점수는 실제 쇼츠 훅 74개로 맞춘 **경험적 기준**이다. 확실히 약한 훅은 잘 거르지만 높은 점수가 조회수를 보장하지 않는다.

## 6. 막혔을 때

| 증상 | 원인 | 해결 |
|---|---|---|
| `/yt-script`가 안 뜸 | 새 스킬은 새 대화에서 인식 | 클로드 새 대화로 다시 열기 |
| 결과가 내 말투가 아님 | voice.md 비어 있음 | 3번 절차 |
| `/yt-retention` 입력 파일이 없음 | CSV 미추출 | 스튜디오 → 영상 → 분석 → 참여도 → 시청 지속 차트 → 다운로드 |
| `/yt-viral`이 채널을 건너뜀 | 채널당 영상 4개 미만이면 중앙값 무의미 | 채널당 4개 이상 수집 (`yt-dlp --flat-playlist -J <채널URL>`) |
| Claude Code 없이 쓰고 싶음 | — | `SKILL.md` 내용을 대화 맨 위에 붙여넣기. 단 파이썬 도구 6개는 못 씀 |
